About Me

Why I Chose IT

My interest in technology began in childhood, when I used my home desktop for the first time to complete a research project. That single moment opened a door I have never wanted to close. As I grew older, I became increasingly curious about how software is built, how systems communicate, and how technology can be used to solve real-world problems. Choosing Information Technology felt less like a decision and more like a natural next step, a way to turn a lifelong curiosity into a meaningful career.

My Career Goals

My goal is to become a skilled IT professional with a strong foundation in software and mobile application development. In the long term, I hope to work on projects that combine creativity with technical precision — building applications that are both useful and secure. I am also eager to expand my knowledge of information systems, so that I can understand not only how technology works, but how it supports people and organisations in meaningful ways.

My Interests in IT

Within the broad world of Information Technology, I am most drawn to mobile application development, cybersecurity, and data analysis. I find mobile development exciting because it puts technology directly into people's hands, while cybersecurity fascinates me because it protects the very systems we rely on every day. Data analysis interests me because it transforms raw information into insight. Together, these areas reflect my desire to build, protect, and understand technology from every angle.

Skills I Am Developing

  • Java programming — building a strong foundation in object-oriented programming and problem-solving.
  • Mobile application development — learning how to design and build functional, user-friendly applications.
  • Cybersecurity fundamentals — understanding how systems are secured, protected, and defended against threats.
  • Web development — applying HTML, CSS, and JavaScript to create responsive and professional websites.
  • Version control with Git and GitHub — managing code, collaborating, and publishing projects professionally.
